# 《笑看华尔街》中文学习版

这是 Chris Camillo《Laughing at Wall Street》的个人中文学习版阅读器。译文按原书序言、引言、第 1–11 章、附录、致谢和注释整理，并保留原书可取得的封面、书名页、作者页、插图和表格。

在线阅读：<https://yiyang-hakimide.github.io/Laughing-at-Wall-Street-ZH/>

阅读器支持目录、章节跳转、上一节/下一节、护眼模式、字号调整、标题层级、引用、列表、表格、图注和图片显示。
